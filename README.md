# Economic Dossier Phase 1 (H1 2026) – Analytical Dashboard (BETA)

Restricted, internal. This is the **beta** revision of the dashboard. The dashboard in `index.html` is encrypted (AES-256-GCM, key derived with PBKDF2-SHA256, 600,000 iterations) and can only be opened in a browser with the passphrase provided by the Policy Planning and Strategic Division, Ministry of Foreign Affairs Malaysia. No readable content is stored in this repository.

The published version is in a separate repository and is not affected by this beta.
